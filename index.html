Importar Planilha de Pendências

Carregue o arquivo .xlsx no mesmo formato do modelo (aba "Pendencia dados"). O painel será recalculado automaticamente.

Gravar a base diretamente no GitHub

Após importar a planilha, publique a base no repositório do GitHub. Assim a última base carregada passa a aparecer automaticamente em qualquer computador que abrir o site — sem precisar reimportar. É necessário um token do GitHub (gravado apenas neste navegador).

Como gerar o token: GitHub → Settings → Developer settings → Personal access tokens. Use um token Fine-grained com permissão Contents: Read and write apenas no repositório Vertical (ou um token clássico com escopo repo). O token fica guardado só no seu navegador e nunca é publicado no site.
Colunas esperadas: Data cirurgia · Descricao grupo de cirurgia · Nome do medico · Paciente · Nome do hospital · Nome do cliente faturamento · Nome do plano de saude · Nome do representante · Valor bruto · Portal · pedido · observação
